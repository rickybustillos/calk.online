# Agenda de Rotinas Diárias

Uma aplicação web para gerenciar e visualizar rotinas diárias com múltiplas formas de visualização.

## Funcionalidades

- ✅ **Gerenciamento de Tarefas**: Adicionar, editar e excluir tarefas
- ✅ **Múltiplas Visualizações**: Timeline, Agenda, Calendário, Gráficos
- ✅ **Estatísticas**: Análise de horas por semana, mês e ano
- ✅ **Tempo de Vida**: Visualização impactante do tempo de vida
- ✅ **Importação/Exportação**: Backup e restauração de dados
- ✅ **Tema Escuro/Claro**: Alternância entre temas
- ✅ **Persistência Local**: Dados salvos no navegador
